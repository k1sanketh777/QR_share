Honest expectations: this is optical broadcast over a camera, not a real data link — realistic throughput is roughly 2–8 KB/sec even well-tuned. It's a solid option when there is truly no network path between two devices, for files up to a few hundred KB. It is not a substitute for WiFi/Bluetooth transfer when either is available.
Note: camera access needs a secure context (HTTPS or localhost). Host this page (GitHub Pages, Netlify Drop, python3 -m http.server on localhost, etc.).
